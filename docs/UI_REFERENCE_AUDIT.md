# 參考網站 UI 研究紀錄

研究截圖只保留本機 docs/reference-ui，不隨公開 GitHub 儲存庫發布；本文件文字紀錄可公開。

查閱日期：2026-11-05（Asia/Taipei）

參考：[Pawscorner 韓國連線下單頁面](https://liff.line.me/2012275055-yxwegxrc)。
登入後由該 LIFF 連結開啟其網站。此為第三方參考，不是本專案已建立的網站。
目前只研究客戶端，不具備第三方管理後台權限。

## 1. 查閱方式與範圍

- 使用者協助完成 LINE 登入後，實際操作前台介面。
- 查看桌面窄版布局及 390 × 844 手機視窗。
- 測試分類、搜尋、規格變價、圖片、尺寸表與購物車。
- 加入一筆暫存商品、調整數量後移除，恢復空購物車。
- 沒有送出正式訂單、付款、發訊或存取其他客戶資料。
- 未查驗後端程式、資料表、第三方管理後台或登入後訂單成立流程。

## 3. 尚未驗證

- 送單成功頁與失敗情況。
- 成立後的訂單明細、收件表單、修改或取消能力。
- 運費、優惠與付款後追加的實際計算及對帳方式。
- 跨裝置購物車、重複送出保護與後端安全。
- 有影片商品、售罄／關閉活動／特殊規格的所有 UI。
- 第三方管理後台、報表、匯入或資料模型。

不得把參考站文案推論成已驗證的內部行為，也不能宣稱已研究所有 UI。

## 4. 本專案的採用與調整

| 方向 | 本專案規劃 |
|---|---|
| 沿用操作概念 | LINE 登入、商品類型分類、名稱／編號搜尋、多圖詳情、規格與購物車、固定底部導覽 |
| 明確改寫 | 「送出預購（目前不用付款）」；「我的訂單」改為「我的預購」 |
| 新增自身需求 | 獨立管理入口、唯一管理帳密、客戶明細、採買彙總、Excel 匯出 |
| 避免擴張 | 不按商家分類，不做結帳、優惠抽獎或付款後追加對帳 |
| 精簡版面 | 無影片就省略影片區，尺寸表依商品需要顯示 |
| 待自行設計 | 預購成立確認、本人明細、追加／修改、採購結果與全部管理 UI |

本專案不沿用第三方商標、產品照片、LIFF ID 或 Channel 設定作為正式素材／帳號。
截圖只作設計研究，不代表取得商品販售或素材發布授權。

## 0.3.2 店主介面修正

依店主 2026-11-05 手機截圖調整：後台長標題不再與匯出按鈕同列擠壓，全站靜態文案移除 br 與多餘句點，改用簡短標題。此為本案偏好，不是參考站研究結論。

## 0.3.4 店主照片管理修正

依店主 2026-11-06 截圖與實際使用回報，商品照片改為多選／拖入／分批追加、縮圖、進度、重試、移除及拖曳／按鈕排序。客戶詳情改顯示全部相簿，不再依顏色數量產生照片；僅明確設定顏色綁定才切圖。這是本案自有介面修正，不是第三方後台研究結論。

## 0.3.5 店主尺寸定價修正

依店主要求改為每個尺寸各自填加價金額，包含 2XL 以上及自訂尺寸，沒有固定把 XL 一起加價。此為本案自有介面需求，不是第三方研究結論。

## 0.3.6 店主手機相簿修正

依店主 2026-11-06 手機詳情截圖加入商品主圖左右滑動與張數提示，同步縮圖並保留點圖放大。原生橫向捲動與 320／390px 版面、較矮視窗上下捲動、末張／放大返回位置已在瀏覽器驗證；未直接操控實體 iPhone。此為本案新增互動，不是第三方研究結論。

## 0.3.8 店主進價紀錄

依店主現場採購需求自行設計匯率設定、韓幣單件進價與台幣即算、進銷合計及未填提醒。320／390／768／1440px 無頁面橫向溢出，驗證儲存重開、舊匯率保留與明確套用目前匯率；此為本案功能，不是第三方管理後台研究。

## 0.3.9 管理預購刪除

依店主要求自行設計兩段刪除操作、摘要、完整編號與原因確認，取消保留原單；隔離瀏覽器驗證 320／390px 對話框無溢出，刪除後客戶重新整理隱藏原單，API 與報表同步排除。此為本案自有管理需求，不是第三方研究結果。

## 0.3.10 商品草稿與離開保護

依店主切換分頁後編輯視窗消失的回報，加入同分頁草稿、重載／重登恢復、外圍保護及保留／放棄操作。隔離 Chrome 實際驗證欄位及尺寸加價重載、恢復後儲存、照片與綁定開關保留、強制到期重新登入恢復；320／390px 底部三個操作可完整顯示。未直接操控實體手機；當次裝置觸發原因未取得事件證據。此為本案修正，不是第三方後台研究。

## 0.3.11 商品編輯進價

依店主補充，進價在商品新增／編輯與採買兩處均可設定，商品欄位為選填，同頁可填匯率。隔離瀏覽器驗證留白上架、即時換算、重載恢復、兩邊同步、混合規格提示、版本衝突載入與保留其他欄位，320／390／768px 無頁面及視窗水平溢出；Excel XML 核對一致。本案自有需求，非第三方後台研究。

## 0.3.12 商品輸出與欄位說明

依店主要求為自己建立的選物加入匯出入口與 XLSX／CSV 下載選擇，附批量新增步驟、欄位範例及可展開中文說明。隔離瀏覽器實際下載 Excel、預覽與新增含尺寸加價／下架商品；320px 匯出視窗及 390px 欄位表無整頁／視窗水平溢出。本案自有需求，非第三方後台研究。

## 0.3.13 含圖商品 Excel

店主要求輸出包含第一張照片、韓幣及台幣進價，未填留空。隔離環境實際下載四款商品（PNG／WebP／JPG／無圖）、10000 韓元／240 台幣、0 元與空白，內嵌圖片與欄位值、ZIP／XML 對應驗證通過。下載按鈕顯示縮圖進度且禁止重複操作。本案自有報表需求，非第三方後台研究。

## 0.3.14 韓國商品連結與空白顏色

依店主要求在商品編輯加入選填來源網址，供匯出記錄；移除新增時的預填顏色。隔離 Chrome 實際確認新表單空白顏色、來源與顏色重載恢復、儲存重開、既有米白／深棕保留；下載 XLSX 的連結位於正確商品列，所有 XML／關聯可解析。320px 欄位及操作無水平溢出。本案自有需求，非第三方後台研究。

## 0.3.18 銷售協助與店主審閱排序

依本案研究與使用者選擇自行設計：瀏覽清單列下一步，明細列依據／步驟／可修改複製草稿；另設商品排序頁，建議先成草稿，可手動調整、套用及載入上次／原始順序。這不是第三方參考站後台行為。實際驗證與發布狀態見 HANDOFF。

0.3.18 隔離環境已確認修改草稿／複製成功提示、資料建議先成草稿、明確套用、載入上次順序後還原套用與重載；排序頁分批顯示 24 款但套用包含完整名單。320／390／768／1440px 無整頁水平溢出；未直接操控實體手機。
