# LINE 一對一聯繫與預購服務

更新：2026-11-08｜版本 0.3.19

## 使用者確認的目的

- 用官方帳號人工一對一服務，不群發，不新增 LINE 付費推播或付費服務
- 客戶在商品詢問或送出預購後，能自然地傳出第一則訊息，讓店主後續服務
- 預購成立時沒有現貨，提供預購圖卡與感謝，再依真實採購結果更新，增加等待期間的信任
- 後台提醒店主處理感謝、採購進度、到台與匯款聯繫，並可安排下一次追蹤
- 沿用到台後才聯絡付款，不新增金流、客戶付款回報或自動收款

## 客戶怎麼開聊

入口包含商品「用 LINE 詢問這款」、購物車協助、送單成功及「我的預購」內的詢問按鈕。

1. 登入會員點選入口，後端只替本人建立一次穩定聯繫碼
2. 畫面顯示聯繫碼、預填內容與 LINE 連結，商品詢問附商品編號／名稱，預購聯繫附預購編號
3. 客戶開啟 LINE，必要時先加入官方帳號，確認後自行按下傳送
4. 店主收到訊息，以聯繫碼對照網站會員，再人工核對聊天室

同一客戶後續詢問與預購沿用相同代碼。聯繫碼不是登入密碼、不賦予網站權限，也不能作為帳號授權憑證。點開入口不代表已傳訊息或已加好友，網站不自動更改聯繫確認狀態。

LINE 官方 URL scheme 支援手機 iOS／Android，官方文件說明不支援 PC；因此也提供「複製詢問文字」與手機搜尋官方帳號 @445yxcey 的備用方式。未直接操控實體 iPhone，連結預填及站內操作於隔離瀏覽器驗證。

來源：[LINE 官方聊天室與預填文字](https://developers.line.biz/en/docs/line-login/using-line-url-scheme/#opening-a-chat-screen-with-a-line-official-account)

## 店主怎麼對照與追蹤

入口：管理「客戶聯繫」，也可從工作總覽提醒、預購明細或瀏覽紀錄的下一步建議進入。

1. 用客戶傳來的聯繫碼搜尋；舊對話可搭配預購編號人工核對，不只憑暱稱
2. 勾選「我已人工核對官方聊天室與此會員」，可填自己的聊天室備註名稱
3. 設定下次聯繫時間（台灣時間）及要確認的事項，再儲存
4. 後台工作總覽與客戶聯繫會在載入／更新時列出到期追蹤與待處理通知
5. 追蹤完成可按「這次追蹤已處理」清除該次時間；不代表已收款或已交貨

本版提醒在網站內呈現，沒有背景排程、LINE 主動推播、作業系統通知或訊息送達偵測。

## 四個服務階段

| 通知 | 可準備的條件 | 內容與限制 |
|---|---|---|
| 預購確認與感謝 | 有效預購有正數明細 | 預購編號、品項／規格、件數、售價快照與預估商品小計；說明代購不保證現貨，付款到台後另行確認 |
| 採購進度 | 此客戶的明細已分配買到或確認缺貨 | 分清全部買到、部分買到、缺貨與待確認；其他客戶的採買數或尚未分配的總量不當作本人的結果 |
| 到台通知 | 活動為「商品已到台」，且本人有分配買到的品項 | 告知已分配買到的件數；待採買與缺貨分開說明，再確認付款與交付 |
| 匯款聯繫 | 同樣需到台且本人有分配買到品項 | 只列已分配買到商品小計，運費、收款資料及最終總額由店主在 LINE 核對後提供 |

所有訊息都可先改寫，再複製至官方帳號原生的個別聊天室。確認人工傳送後，才在網站按「我已在 LINE 人工傳送」。此標記只表示店主自己的作業紀錄，不表示 LINE 送達／已讀，更不表示付款。

人工核對聊天室前可以準備圖卡與文字，但不能標記已通知。通知紀錄使用版本及內容簽章；預購、採購分配或相關階段變動時，舊通知會重新列為需確認，舊畫面不能覆蓋新版本。已刪除或數量為零的預購不列通知。

## 訂單圖卡

- 圖卡由店主瀏覽器依私有預購資料產生 1080×1600 PNG，顯示目前選擇的服務階段
- 使用已成立預購的商品名稱、規格、價格快照及客戶分配結果；不依目前商品售價重算歷史
- 長名稱自然換行，所有有效明細分頁保留，逐張下載再附加至官方帳號個別聊天室
- 每頁標明整份商品小計與頁數，避免把分頁當成多份訂單；採購／到台／匯款卡只以已分配買到金額計小計
- 不帶進價、匯率、電話、地址、內部追蹤備註或 Token；不放公開 Storage，也不保存私人圖片到原始碼
- 圖卡只記錄產生時讀到的資料，人工傳送前應更新並核對客戶及訂單。標記通知時後端會再次核對版本與內容

## 免費一對一方式

網站只準備 LINE 連結、文字與圖片，不呼叫 Messaging API Push，不替店主傳訊息。依 LINE 官方費用說明，官方帳號原生一對一聊天不列入訊息費用；是否已有其他月費或加購，仍以店主原帳號設定為準，本次未變更 LINE 方案。

來源：[LINE 一對一聊天與訊息費用](https://tw.linebiz.com/column/budget-auto-count/)、[官方帳號聯繫限制](https://help.line.me/official_account_tw/web/pc?contentId=200001206&lang=zh-Hant)

## 資料與工程界線

- 雲端使用既有私有 JSONB：customers[].contact_code、customerCare、orderNotices；仍由 revision 原子提交與每次角色驗證保護，沒有新的公開資料表或訊息密鑰
- 本機新增 customers.contact_code 及唯一索引、customer_care、order_notices，保留現有資料
- 客戶只能建立／讀取自己的聯繫碼；照顧備註、聊天室核對與通知紀錄限店主，客戶 me／catalog／orders 不帶管理欄位
- 聯繫碼與作業紀錄納入既有私有 JSON 備份；瀏覽事件仍依原獨立保存規則
- 通知圖卡與草稿不代表發票、付款請求、收據或供貨保證；本版沒有自動配對 webhook、收款對帳與付款完成狀態
