## 後續順序

1. 使用者先看本機前後台，調整視覺與操作。
2. 品牌已確認為 CCBABY；補入正式 Logo、實際商品、活動日期與必要營運規則。
3. 決定正式主機後，接上自有 LINE 登入與部署所需後端環境。
4. 依正式使用需求補齊跨年度、匯入、圖片與完整備份還原。
5. 逐項完成 SPEC 的正式驗收，再交付真實客戶使用。
