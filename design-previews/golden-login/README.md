## 行為與文字

初始「正在確認 LINE 登入…」與「正在開啟 LINE 登入」仍是原文字，只增加裝飾性影片。所有原本的標題、說明、取消／失敗與重試按鈕保留；沒有新增假進度、倒數或最低播放秒數。動畫失敗、模組失敗或自動播放被拒絕，登入仍照常；成功立即進站，快速完成則略過影片請求。減少動態效果只顯示靜止圖，背景／離開或等待節點消失即停止。

改善主觀等待感是設計目的，沒有做使用者研究或宣稱量測成效。圖片、影片及 optional 模組仍有少量傳輸／繪製成本，不宣稱零開銷；登入鏈沒有新增 await 或 API。
